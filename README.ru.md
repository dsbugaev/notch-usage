# NotchUsage

Наводишь курсор на чёлку MacBook - выпадает панель со статусом лимитов по токенам всех профилей Claude Code сразу: сессия 5 часов, неделя (и неделя Opus, если приходит), процент израсходованного и время сброса по каждому аккаунту.

Сделано потому, что готовые notch-трекеры не умеют несколько аккаунтов Claude (личный + рабочий через `CLAUDE_CONFIG_DIR`) одновременно.

## Как работает

- Данные - тот же эндпоинт, что у экрана `/usage` в самом Claude Code.
- OAuth-токены читаются из связки ключей macOS (записи `Claude Code-credentials*`, которые ведет сам Claude Code). Для профиля через `CLAUDE_CONFIG_DIR` имя записи - `Claude Code-credentials-<первые 8 hex sha256(путь)>`.
- Токены не уходят никуда, кроме api.anthropic.com; refresh-токен не трогается - разлогинов не будет.
- Наведение - опрос позиции мыши (80 мс), Accessibility-разрешение не нужно.
- Обновление: фоном раз в 5 минут + при наведении, если данные старше минуты.

## Установка

```bash
./install.sh
```

Первый запуск: macOS спросит доступ к связке ключей (по диалогу на профиль) - жми "Разрешать всегда". Чтобы разрешение переживало пересборки, один раз доверься сертификату подписи (команда в англоязычном README, раздел Install) - без этого macOS не может проверить самоподписанную подпись и спрашивает заново после каждой сборки.

Обновление: `git pull && ./install.sh`. Удаление: `./uninstall.sh`.

## Конфиг

`~/.config/notch-usage/config.json` - генерируется при первой установке из реально существующих каталогов профилей (`~/.claude` + все `~/.claude-*`), так что с одним профилем в панели будет одна секция. Поля: список аккаунтов (`name` + `configDir`), интервал `refreshSeconds`, локаль `locale` (например `ru_RU`), русские подписи окон лимитов через `labels` (полный формат - в `config.example.json`). Шестеренка в панели открывает конфиг в редакторе; сохраненные правки подхватываются сами в течение секунды, перезапуск не нужен.

## Диагностика

`--print` (статусы в терминал), `--kc-debug` (сопоставление записей связки ключей, без секретов), `--selftest` (юнит-проверки), `--demo` (панель с тестовыми данными), `--show` (принудительно показать панель один раз); лог - `~/Library/Logs/notchusage.log`.

Сообщения в панели: "token expired" - токен протух, любой запуск `claude` обновит; "keychain access denied" - нажат "Запретить", кнопка обновления в панели спросит заново; "no keychain record" - в профиле не выполнен `/login`; "keychain record unreadable" - запись есть, но токен в ней не разобрался, поможет повторный `/login`.
